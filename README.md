# Simulated SOC Investigation: Detecting and Mitigating a DoS Attack

## Project Overview
This project simulates a Security Operations Center (SOC) investigation into a Layer 7 Denial-of-Service (HTTP Flood) attack targeting a web application (`www.yummyrecipesforme.com`). It demonstrates the ability to analyze web server logs, identify malicious traffic patterns, and propose mitigation strategies.

👉 **[View the Live SOC Dashboard Here](https://[your-username].github.io/soc-dos-investigation/)** ## The Scenario
On a Tuesday afternoon, the application became unresponsive. Internal monitoring tools triggered alerts for critical CPU utilization (peaking at 99.9%) and severe network latency. As the responding SOC Analyst, my objective was to investigate the traffic anomalies, identify the attack vector, and recommend immediate remediation steps to restore service availability.

## Tools & Technologies Used
* **Log Analysis:** Linux Command Line (`grep`, `awk`, `sort`, `uniq`)
* **Data Source:** Apache/Nginx web server access logs
* **Threat Identification:** Volumetric DoS / HTTP Flood
* **Documentation:** Incident Response Reporting
